# Game covers

960x600 (16:10) WebP covers, one per game id, each under 80 KB, all in one flat 2D store-icon style: a blurred, darkened scene of the game's own scenery, a centred rounded icon box with the game's main subject, and the game name in white Montserrat. Every cover is drawn as SVG (no photos, no 3D renders, no official artwork) and rendered with Chrome via Playwright. Preview: `contact_sheet.jpg`.

Tools: `../agents2/covers/flat/` (`kit.js` SVG helpers and layout, `art/*.js` one icon + background per game, `render.js [ids]` renders PNGs, `enc.py [ids]` encodes WebP and the contact sheet; set `COVER_OUT=<this folder>` to write here). The older Blender/official-art tools in `../agents2/covers/` are no longer used.
