# Game covers (key art)

960x600 (16:10) WebP covers, one per game id, each under 80 KB. Remakes of known games use the official artwork (App Store icons, Steam store art, web portal covers, Wikipedia box art), fitted without stretching; source URLs in `SOURCES.md`. Games with no well-known cover use original key art rendered with Blender 5.2 Cycles plus a title wordmark (no generative AI). Preview: `contact_sheet.jpg`.

Sources and tools: `../agents2/covers/` (`scenes/<id>.py` Blender scene per game, `specs.py` logo and grading per game, `make.py` post + compose + WebP, `runfinal.sh <ids>` to rebuild renders, `official.py <ids>` to rebuild official covers from `official/`).
